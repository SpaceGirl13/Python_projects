# Tetris

Play in your browser: https://spacegirl13.github.io/Python_projects/

## Run on your computer

```
pip install -r requirements.txt
python Tetris_game/main.py
```

Controls: Left / Right to move, Up to rotate, Down to drop fast.

The web version is built with [pygbag](https://github.com/pygame-web/pygbag) and deployed to GitHub Pages by `.github/workflows/deploy-pages.yml` on every push to `main`.
